# Atlas Command Interface

The command interface is what an operator uses to run Atlas. It shows Assets and their Tasks, and sends Core the operator's commands and settings changes. Protocol calls it an operator interface.

**Planning.** No code yet. This folder will say how the command interface works, so Core can rely on that behavior instead of guarding against an interface that misbehaves.
