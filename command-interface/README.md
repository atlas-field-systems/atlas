# Atlas Command Interface

The command interface is what an operator uses to run Atlas. An operator logs in
to an account, watches Assets and their Tasks, and sends Core Tasks and settings
changes through the [Core API](../core/docs/api.md).

**Planning.** No code yet. The [selected behavior](docs/README.md) describes a
command-station application with a RidgeLine map, linked inspection, and
separate detail pages.
