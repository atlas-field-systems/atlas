# Atlas is an experiment platform for one field tester

Atlas is an experiment platform for the owner testing drones and sensors in the field, until the owner changes that expectation. Usually one operator works with several Assets, and sometimes several operators share one picture. Its job is to receive Asset data and Observations and send commands, filling the gap between single-drone ground stations and a shared picture built from several Assets.

Operators task each Asset individually from a command station through Core, so new work requires Core to be reachable. Manual piloting, swarm planning, separate teams, field-phone use, and support for every vehicle are out of scope for now. Quadcopters come first.
