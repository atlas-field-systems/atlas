# The Fieldlink moves messages; the Asset decides

A Fieldlink moves messages and reports link facts, including lost contact and available capacity. The Asset owns its response and its report priorities, keeping each decision with the part that knows current state.

On IP and every Fieldlink, when the link has room, it asks for up to that capacity and the Asset supplies its highest-priority waiting reports. Each Fieldlink determines capacity from its own medium and current link quality.
