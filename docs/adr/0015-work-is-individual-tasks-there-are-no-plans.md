# Work is individual Tasks; there are no Plans

Operators request all work as individual Tasks. Atlas has no multi-step Plans.

Why: one action sends an ordered sequence while each step stays visible and cancelable. A Plan would add a second identity with no good status for a half-finished Plan, and the owner wants the Task system kept simple.
