# The drawer

Ideas Atlas may want one day that no part owns yet. The goal is an empty
drawer. Each item leaves when a part adopts it into its own docs, or when the
owner drops it.

- Nothing here is designed, decided, or built.
- Each item says what takes it out of the drawer.
- Items marked **Keep room** are ones the owner wants one day. Today's work must
  not rule them out, and must not grow to make room for them.
- Superseded plans go to [the archive](../../atlas/archive/README.md), not here.
  The archive holds the past. The drawer holds ideas for later.
