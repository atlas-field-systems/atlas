# Following a Track

**Keep room.** Depends on [Fusion and Tracks](fusion.md). Today a command only
names a position, so an operator can send an Asset to where a target is now, not
tell it to follow a Track. A later command will make an Asset keep following a
Track.

Out of the drawer when: [Fusion and Tracks](fusion.md) leaves the drawer and the
Follow command is designed in Protocol and Asset docs.
