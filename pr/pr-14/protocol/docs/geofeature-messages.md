# Geo features and Objects: the messages

Generated by `npm run scenarios` from `examples/geofeature/`. Do not edit by hand.

An operator interface receives the geo features and Objects Core holds, makes a geo feature, sends an Asset to it, edits and deletes geo features, and sees an edit refused.

Every message below is a real example file, checked against its definition by `npm test`.
Sizes are bytes: minified JSON, then deflate (level 9). GAP marks something the flow needs that the protocol does not have yet.

## Observations on verbosity

17 messages, 2980 bytes minified, 2170 bytes if each is deflated on its own.

The header (`type`, `time`, `seq`, `asset_id`) is 30% of all bytes. Field names, quotes and punctuation are 59%; the values themselves are the rest.

Deflate saves little on one small message, because there is little repetition inside it. Compressing many messages together would find the repeated field names.
