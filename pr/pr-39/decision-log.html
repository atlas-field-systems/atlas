Decision log

The owner's product decisions, newest first. This page is authoritative: when another page disagrees with it, that page is wrong. Each entry names its scope, so a rule is never stretched past it, and the one page that owns the detail.

Only the owner adds or changes an entry. A thread's recommendation is not a decision until the owner makes it. Atlas is still a draft, so any entry may be reversed. A reversal updates this log and, in the same pull request, every page that still teaches the old rule, and adds the old wording to the retired phrases so CI catches it coming back.

Dates are when the owner decided (America/New_York).

A gateway removed and not replaced leaves its radio Assets offline but still the same Assets. Takeover happens only when the old carrier is offline, removed, or none. Within a run. 2026-11-11 Carried between runs: accounts, connection keys, and installed Plugin setup. Not carried: Asset IDs, the run's picture, and operator state. Across runs. Runs and identity

Places and Tasks

Date Decision Scope Home
2026-11-11 A Task holds a live reference to a place (geofeature_id). The Asset obtains the current shape; Core never copies or snapshots it. Assets get read access to the named place only. Edits reach the Asset as geofeature.replaced or geofeature.deleted. A named place. A shape drawn into one Task is carried by that Task. Core API, geo features
2026-11-11 Place edits and deletes go through while Tasks use the place. Core blocks nothing and cancels nothing; each Asset may keep its original plan or follow the new shape. Places named by unfinished Tasks. Asset behavior
2026-11-11 Core refuses a place that is not a point for move_to and land. Those two commands. Core API, geo features
2026-11-11 Imagery is a fourth place kind, beside point, line, and area. It can only be renamed. The imagery must be deleted before the file it shows (409 otherwise). Photo detection is removed. Places and Objects. Core API, geo features
2026-11-10 The Task cap is 64 ordinary Tasks; a now Task is admitted even at 64. Per Asset, outstanding work. Core API, operator requests
2026-11-10 Hold is an ordinary command, like Land. It is not pause: it keeps no earlier Task to resume. Commands. Pause stays a setting. Protocol decisions

2026-11-11 During a failsafe the operator may override with Land, Return to home, or Hold sent with now, or with pause. Failsafe state. Failsafes
2026-11-11 A failsafe that has fired can't be cancelled or left; the Asset stays in failsafe state until it shuts down. Failsafe state. Failsafes
2026-11-11 Failsafe boundaries are drawn separately from saved places; a failsafe response can't name a saved place. Failsafe rules. Failsafes
2026-11-11 Up to 16 failsafe rules and 16 pieces of equipment (subsystems) per Asset. Per Asset. Protocol decisions
2026-11-10 Any operator may change failsafe rules. Outside failsafe state. Failsafes
2026-11-10 Low battery is a set percentage, not an estimate of the charge needed to get home. Battery rules. Failsafes
2026-11-10 A failsafe rule may react to degraded or faulted equipment. Declared subsystems. Subsystem conditions
