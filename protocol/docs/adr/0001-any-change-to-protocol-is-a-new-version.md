# Any change to Protocol is a new version

Any change to Protocol files is a new version, including wording. Wording fixes wait for the next real release, and every part updates together. The definitions hash checks exact file contents, so programs agree only when they use the same definitions.

Rules: [Definitions hash](../decisions.md#definitions-hash), [Changes and releases](../../../atlas/design-decisions.md#changes-and-releases)
