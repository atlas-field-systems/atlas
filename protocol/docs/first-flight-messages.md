# First flight: the messages

Generated by `npm run scenarios` from `examples/first-flight/`. Do not edit by hand.

Charter first-flight.md: power on, connect through a gateway, Takeoff, Move To, Land, with the failure branch.

Every message below is a real example file, checked against its definition by `npm test`.
Sizes are bytes: minified JSON, then deflate (level 9). GAP marks something the flow needs that the protocol does not have yet.

## Observations on verbosity

32 messages, 5277 bytes minified, 4024 bytes if each is deflated on its own.

The header (`type`, `time`, `seq`, `asset_id`) is 40% of all bytes. Field names, quotes and punctuation are 61%; the values themselves are the rest.

Deflate saves little on one small message, because there is little repetition inside it. Compressing many messages together would find the repeated field names.

Where the bytes go (each field summed across every message):

|---|---|---|---|
| `type` | 32 | 731 | 14% |
| `time` | 32 | 640 | 12% |
| `asset_id` | 32 | 480 | 9% |
| `from` | 32 | 366 | 7% |
| `seq` | 32 | 240 | 5% |
| `kind` | 16 | 223 | 4% |
| `task_state` | 8 | 180 | 3% |
