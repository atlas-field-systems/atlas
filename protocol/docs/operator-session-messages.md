# Operator session: the messages

Generated by `npm run scenarios` from `examples/operator-session/`. Do not edit by hand.

An operator interface on its own WebSocket: hello, the pushed picture, a repeating query, a command accepted, one refused, and a cancel.

Every message below is a real example file, checked against its definition by `npm test`.
Sizes are bytes: minified JSON, then deflate (level 9). GAP marks something the flow needs that the protocol does not have yet.

## Observations on verbosity

22 messages, 3227 bytes minified, 2554 bytes if each is deflated on its own.

The header (`type`, `time`, `seq`, `asset_id`) is 44% of all bytes. Field names, quotes and punctuation are 59%; the values themselves are the rest.

Deflate saves little on one small message, because there is little repetition inside it. Compressing many messages together would find the repeated field names.
