# Plugin call: the messages

Generated by `npm run scenarios` from `examples/plugin-call/`. Do not edit by hand.

An operator interface learns which Plugins Core has, runs a Plugin action, asks for the Plugin list again, and sees a call that fails.

Every message below is a real example file, checked against its definition by `npm test`.
Sizes are bytes: minified JSON, then deflate (level 9). GAP marks something the flow needs that the protocol does not have yet.

## Observations on verbosity

11 messages, 1557 bytes minified, 1277 bytes if each is deflated on its own.

The header (`type`, `time`, `seq`, `asset_id`) is 36% of all bytes. Field names, quotes and punctuation are 55%; the values themselves are the rest.

Deflate saves little on one small message, because there is little repetition inside it. Compressing many messages together would find the repeated field names.
